# DP001 Media QA Checklist

Every image/clip must be checked against the following criteria before approval.

## Property continuity

- [ ] Same roof form.
- [ ] Same external materials.
- [ ] Same glazing system.
- [ ] Same pool position.
- [ ] Same building footprint.
- [ ] Same garden/site relationship.

## Australian context

- [ ] Architecture believable for Sydney/NSW.
- [ ] Landscaping believable.
- [ ] Road/neighbourhood cues not obviously foreign.
- [ ] Northern Beaches environment credible.

## Photography

- [ ] Professional composition.
- [ ] Realistic perspective.
- [ ] Level verticals.
- [ ] No excessive wide-angle distortion.
- [ ] Sharp enough for premium web presentation.

## Light/grade

- [ ] Consistent late-afternoon/golden-hour timing.
- [ ] Neutral whites.
- [ ] No excessive yellow/orange.
- [ ] Realistic skin-free property photography colour.
- [ ] Foliage remains natural.

## AI defects

Reject if there are any of the following. Confirm each is absent:

- [ ] Warped architecture.
- [ ] Impossible windows.
- [ ] Inconsistent doors.
- [ ] Duplicate furniture.
- [ ] Malformed fixtures.
- [ ] Impossible reflections.
- [ ] Changing pool geometry.
- [ ] Changing roof geometry.
- [ ] Invented structures.
- [ ] Visible generation artefacts.

## Motion-specific

Reject clips with any of the following. Confirm each is absent:

- [ ] Bending walls.
- [ ] Moving fixtures.
- [ ] Shifting furniture.
- [ ] Morphing landscaping.
- [ ] Changing property structure.
- [ ] Impossible camera movement.
- [ ] Excessive synthetic motion.

## Approval statuses

Use only:

**GENERATED → REVIEW → APPROVED → MASTER → WEB → LIVE**

Only **APPROVED** assets may enter production.

An asset that fails review remains in REVIEW; it must not advance to APPROVED or downstream stages. MASTER, WEB and LIVE preserve the approval requirement and do not replace it.
