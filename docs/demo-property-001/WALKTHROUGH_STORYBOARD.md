# DP001 Homepage Walkthrough Storyboard

## Purpose

Demonstrate how an already-completed professional property shoot becomes additional premium Caplist products.

The walkthrough is a directed product showcase, not a fake interactive demo.

## Source media

**27 professional photos · Drone media**

Do not show professional property video as an input in this specific walkthrough.

Video remains a Caplist capability elsewhere on the website.

## Asset A

Finished Caplist media products:

- **A1 — 16:9 Mixed Media Reel**
- **A2 — 9:16 vertical derivative created from the same DP001 source media**

A1 is used inside the homepage walkthrough.

A2 demonstrates that the same property capture can support another finished format/product.

This does not claim to validate landscape-video-to-vertical-video reframing.

## Asset B

Homepage Caplist walkthrough built in React/CSS using the approved site UI.

Higgsfield generates property media and selected motion only.

Higgsfield does not render:

- Caplist logo.
- UI text.
- Buttons.
- Product cards.
- Progress bars.
- Software interface.

## Scene 04 — Finished product

Target duration: approximately 10–12 seconds.

Locked headline:

> More premium products, ready to sell to the same client.

Insert the actual approved 16:9 DP001 Mixed Media Reel.

Show:

> MIXED MEDIA REEL

> Bring the best of the property capture together.

Footer/source label:

> Photography + Drone media

Implement:

- Replay.
- Real mute/unmute only if music is present.
- Reduced-motion fallback.

## Target total duration

Approximately 20–24 seconds.

## Audio

Walkthrough must work perfectly silent.

If music is used:

- Autoplay muted.
- User may enable sound.
- No fake sound control.

## Implementation boundary

This storyboard defines future DP001 production and integration. Leave the current homepage walkthrough placeholder exactly as it is until the finished DP001 walkthrough is ready for a separately authorised integration.
