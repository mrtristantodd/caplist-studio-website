# Homepage review routes

The homepage concept comparison is intended for design review only.

Planned review routes:

- `/concepts` — comparison index
- `/concepts/editorial` — Concept A: editorial / text-led
- `/concepts/animated` — Concept B: animated product walkthrough

All review routes use `noindex, nofollow` metadata and are not linked from the public navigation or sitemap.

The production homepage should remain unchanged until a concept is selected and the final messaging/design pass is approved.
