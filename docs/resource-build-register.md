## Format rules

- Public resources are web-first and indexable. PDF is a derived format only where useful.
- Partner commercial resources are authenticated by default.
- Agent-facing partner collateral may be shareable, but must never expose Caplist wholesale cost, partner margin, internal scripts or reseller mechanics.
- Product sell sheets use responsive web/app as the canonical version and A4 portrait PDF as the derived version.
- Agency presentations use 16:9 as the canonical presentation format with PDF export.
- Margin tools remain interactive; no static spreadsheet is the canonical product.
- Demo media should show `source media → Caplist output` wherever possible.
- All materials inherit the Caplist Studio design system and use the existing media/output language rather than generic AI imagery.
